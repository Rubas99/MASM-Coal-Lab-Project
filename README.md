# MASM Project

## Description
This project was developed using
Microsoft Macro Assembler (MASM).

## Requirements
- Visual Studio
- MASM
- Irvine32 Library

## How to Run
1. Open MASM_Project.sln in Visual Studio.
2. Ensure Irvine32 is configured.
3. Build the solution.
4. Run the program.
